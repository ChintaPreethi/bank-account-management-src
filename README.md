# 🏦 Bank Account Management System

A simple Java console-based Bank Account Management System that allows users to manage a bank account and perform basic banking operations.

The project demonstrates important Java Object-Oriented Programming concepts such as classes, objects, encapsulation, methods, and `ArrayList`.

## ✨ Features

* 👤 Create a bank account
* 🏦 Store account number and account holder name
* 💰 Set initial balance
* 📊 Check account balance
* 💵 Deposit money
* 💸 Withdraw money
* 📋 View account details
* 🧾 View transaction history
* ✅ Validate deposit and withdrawal amounts
* 🚫 Prevent withdrawal above available balance

## 🛠️ Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Scanner
* Loops
* Conditional Statements
* Switch Statement

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd bank-account-management
```

### 3. Navigate to the source folder

```bash
cd src
```

### 4. Compile the Java files

```bash
javac BankAccount.java BankAccountManagement.java
```

### 5. Run the application

```bash
java BankAccountManagement
```
